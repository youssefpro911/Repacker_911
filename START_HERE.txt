RPK — WINDOWS X64 QUICK START
==============================

1. Extract the complete RPK-Windows-x64 ZIP to a normal folder.
2. Run rpk_gui.exe to open the dark Windows compression workspace.
3. Choose a source folder and an output .rpk archive.
4. Use Analyze source to inspect file classifications and entropy.
5. Start Jan Desktop and its Local API Server if you want model-assisted settings.
6. Click AI Assistant — Jan to configure the Jan URL/API key and select your model.
7. Return to RPK Builder and click Optimize with Jan to get validated settings.
8. Click Build archive. Adaptive codec mode probes representative samples for each file group.
9. Verify the resulting archive before sharing or deleting source data.
10. Use Verify archive and Extract archive to restore files; SHA-256 checks protect file integrity.

Included:
- rpk_gui.exe  Windows graphical application
- rpk.exe      Command-line application
- rpk_setup.exe SFX extraction stub used by the rpk sfx command
- rpk_ai.exe   Jan local API assistant window

Jan setup details are in AI-SETUP.md. RPK does not require Ollama or a separate llama.cpp CLI.
The optional Jan app and model are installed separately; RPK connects to Jan on localhost.

This is a portable package. No local compiler or CMake installation is required.
